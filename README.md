# Data Analytics Portfolio

Hi, I'm **Amal Shesnij**, a finance professional moving into data analytics.

My background is in financial operations at a garment manufacturing company: accounts receivable and payable, ledger reconciliation, GST compliance, payroll and monthly financial reporting. I now work freelance, preparing ledgers and MIS reports for small businesses, while building my analytics skills full time. This repository is where that work lives.

I'm pairing it with the technical toolkit to work with data at scale.

## Projects

### Python
- **[Retail Customer Analysis](Python/Retail-Customer-Analysis)**: merged customer, transaction and product data (23,000+ transactions) to analyse sales by channel, city, gender and age group. Handled mixed date formats, duplicate rows and a composite-key join. Key finding: e-Shop drives about 41% of net sales, while gender barely affects category preference.

### SQL

### Power BI
